# CowSpaceGame

## Game Overview
A simple space-themed shooter game. Play as a cow in space and shoot projectiles to eliminate aliens, fight bosses, collect power ups, and gain points!

## How to Run
Built with Processing.
Processing version: Processing 4.0.1
Main sketch and project folder: SpaceGame
Required libraries, if any: GifAnimation, processing.sound

1. Open Processing (version 4.0 or higher).
2. Ensure gifAnimation and Sound libraries are installed.
3. Open SpaceGame.pde from the SpaceGame project directory.

## Controls
Use WASD to control movement, left click to shoot.

### Three Power-Up Types
1. HP — Addes 10HP to user
2. DoubleTurret — Gives user a turret for 5 seconds
3. Shield — Gives user a shield to avoid damage for 5 seconds

### Levels
After eliminating 10 aliens, a boss appears, which fires projectiles and moves horizontally. Beating the boss allows progression to level 2, which has faster-moving aliens.
